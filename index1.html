The assignment

Daily prices arrive often, but analysts want a calmer monthly view. The task is to reshape the data and add indicators traders use.

What was given

  • One CSV with 2 years of daily prices for 10 tickers
  • Columns: date, volume, open, high, low, close, adjclose, ticker
  • Tickers: AAPL, AMD, AMZN, AVGO, CSCO, MSFT, NFLX, PEP, TMUS, TSLA
  • Python with Pandas only, no technical-analysis libraries

What was asked for

  • Daily to monthly: open = first day, close = last day, high = max, low = min
  • SMA 10 & 20, EMA 10 & 20, Donchian channels, Bollinger bands, Z-score
  • All indicators based on monthly closing prices
  • 10 files named result_{SYMBOL}.csv, 24 rows each
  • Modular code: calculation separate from file writing

How it will be judged, and where each part lives

What I built

A single script, main.py, that runs the whole journey from raw CSV to ten checked output files.

Calculated for every stock

    Safety checks built in

    • All expected columns and exactly the 10 expected tickers are present
    • No duplicate (ticker, date) rows
    • Each stock ends up with exactly 24 sorted, unique months
    • The files are re-opened after saving and checked again

    Architecture

    The script runs these steps in order. Each step is its own function so the maths never mixes with file writing.
